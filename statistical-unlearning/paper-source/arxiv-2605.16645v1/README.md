# Paper source checkpoint

Text files extracted from the arXiv v1 source archive at
https://arxiv.org/src/2605.16645v1. Pandey and Kulkarni,
*Statistical Unlearning of Distributions: A Hypothesis Testing Approach*,
https://arxiv.org/abs/2605.16645v1, CC BY 4.0:
https://creativecommons.org/licenses/by/4.0/.

These files are an unchanged extraction of the source text (TeX, bibliography,
and style); binary figures have not yet been extracted. This is a development
checkpoint, not a complete source archive or a publication-ready conversion.
`neurips_2026.tex` is the root document. See `docs/MATHJAX_READER_WORK.md`.
