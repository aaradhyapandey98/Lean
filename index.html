The purpose of this project is to explore a space of formalized mathematics in Lean and to provide a clean interface for browsing results, proofs, and computational experiments.

This page is intentionally minimal: a header band with navigation buttons (as in the reference), followed by a large diagram, then explanatory text and links.

What this project contains

  • A growing library of Lean files proving implications and non-implications.
  • Generated data and exports (text / JSON) for downstream tools.
  • Exploration tools for browsing equations, models, and graphs.

Build instructions

After installing Lean and cloning the repository, run:

% cd your_project/
% lake exe cache get
% lake build
